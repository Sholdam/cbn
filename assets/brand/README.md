# Assets de Marca — CBN Crédito

Este diretório registra os tokens e as regras de uso da identidade visual da CBN Crédito.

Os arquivos binários oficiais da marca são mantidos no Google Drive para preservar a versão aprovada e facilitar o uso pela equipe:

- Pasta oficial: https://drive.google.com/drive/folders/18nhsvFGnKOae7wdMDDbO2Sryb3IC-Xxq
- Logo para fundo escuro: https://drive.google.com/file/d/1w_3J_Xc92GO_EOTVTLikYsPWhT_47GgF/view
- Logo para fundo claro: https://drive.google.com/file/d/1RbRVr3hjOSXimZKN_OUYUKSe1K_0hWkC/view
- Símbolo isolado: https://drive.google.com/file/d/1LulOVtWg4_i4D6mBm-BaFWI2KjyXq9gK/view

## Regras

- Não redesenhar a marca.
- Não alterar cores, proporções ou tipografia.
- Usar a versão apropriada ao fundo.
- Logo completa na capa e no encerramento de carrosséis.
- Páginas internas usam `@cbncredito`.
- Consultar `docs/BRAND_IDENTITY.md` e `docs/SOCIAL_MEDIA_PLAYBOOK.md` antes de criar novos conteúdos.
